# Observability

- Logs: ECS structured console. One line per request; `X-Correlation-Id`
  honored/generated by `CorrelationIdFilter` into MDC `correlationId`; trace
  ids automatic via the Micrometer–OTel bridge.
- Metrics: `/actuator/prometheus` with `application` tag;
  `http.server.requests` histograms on; Resilience4j registries export when
  the module is enabled.
- Tracing: OTel bridge, sampler `TRACING_SAMPLING_PROBABILITY` (0.1 default,
  raise briefly for incidents); exporter endpoint
  `OTEL_EXPORTER_OTLP_ENDPOINT` (empty = no export).
- Info: `/actuator/info` exposes app name/version for deploy tracking.
